## Project Description
This Dyslexia Reading Aid is a specially designed reading aid for Dyslexic individuals as well as those with colour blindness and other reading difficulties.

## Access Link
https://dyslexia-tts-aid.streamlit.app/

## What sets this solution apart from others?
1. Text segmentation
2. Text-to-Speech (with pause and replay)
3. Real-time word-to-word and sentence-to-sentence text highlighting
4. Highlighting Speed adjustments
5. Customisable interface
6. Short learning curve for new users
7. Free of cost!
